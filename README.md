# GREEN-API Telegram Chat

Минималистичный React-интерфейс для отправки и получения текстовых сообщений Telegram через GREEN-API.

## Демо

[Открыть приложение на Vercel](https://green-api-telegram-chat-nine.vercel.app/).

Для работы нужен собственный авторизованный Telegram-инстанс GREEN-API. Параметры подключения вводятся в приложении; серверные переменные окружения не требуются.

## Деплой

Проект подключён к Vercel. Изменения в ветке `main` публикуются автоматически. Настройки сборки находятся в `vercel.json`: Node.js 24.x выбран в проекте Vercel, установка — `npm ci`, сборка — `npm run build`, результат — `dist`.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Подключение

В приложении введите `apiUrl`, `idInstance` и `apiTokenInstance` авторизованного Telegram-инстанса из личного кабинета GREEN-API. Telegram API GREEN-API сейчас находится в бета-версии.

Для получения входящих уведомлений настройте инстанс для HTTP API в личном кабинете: оставьте `webhookUrl` пустым и включите входящие уведомления. Приложение последовательно вызывает `ReceiveNotification`, обрабатывает текстовые сообщения всех добавленных чатов и подтверждает каждое уведомление методом `DeleteNotification`.

## Диалоги

Новый чат можно найти по международному номеру телефона или публичному Telegram username (`@username`). Приложение проверяет аккаунт через `CheckAccount`, получает `chatId` и использует его для отправки сообщений.

Чтобы удалить диалог, откройте меню «⋯» в его шапке и выберите «Удалить чат». После подтверждения диалог и его история удаляются из приложения и сохранённой сессии вкладки. Переписка в Telegram сохраняется. После удаления открытого чата выбирается первый оставшийся, а после удаления последнего появляется начальный экран.

## Архитектура

- `src/api/` — типы и Axios HTTP-клиент GREEN-API;
- `src/features/connection/` — форма параметров подключения;
- `src/features/chat/` — поиск адресата, TanStack Query mutations, чат и HTTP long polling входящих сообщений;
- `src/features/session/` — сохранение и восстановление сессии вкладки;
- `src/app/` — тема Mantine, `QueryClientProvider`, композиция приложения и глобальные стили.

Подключение, API-токен, список диалогов, сообщения и выбранный чат сохраняются в `sessionStorage` при каждом изменении и восстанавливаются после перезагрузки страницы. Хранилище относится к текущей вкладке; кнопка отключения удаляет сохранённую сессию. `localStorage` не используется.

Повторное сохранение настроек того же инстанса сохраняет переписку. Подключение другого инстанса начинает новую сессию. При недоступном или переполненном хранилище приложение показывает ошибку сохранения.

Если страница перезагружена во время отправки сообщения, результат отправки отмечается как неизвестный: перед ручным повтором нужно проверить Telegram. Автоматическая повторная отправка не выполняется.
